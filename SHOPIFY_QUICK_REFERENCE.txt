🚨 COMMON ISSUES & FIXES

Issue: "Invalid redirect URI"
Fix:   Make sure URI in Shopify matches exactly
       Check for trailing slashes and http/https

Issue: "Client ID not found"
Fix:   Verify .env file exists
       Check environment variables are set
       Restart app after changing .env

Issue: Chatbot not appearing
Fix:   Check theme permissions were granted
       Verify widget URL is accessible
       Clear theme cache (Shopify admin)

Issue: CORS errors
Fix:   Check API_BASE in shopify-connect.html
       Update to match your server URL
       Add domain to CORS whitelist
