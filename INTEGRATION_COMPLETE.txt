🚀 5-MINUTE QUICK START
───────────────────────────────────────────────────────────────────────────────

Step 1: Get Shopify Credentials (2 min)
  → Go to: https://partners.shopify.com
  → Create custom app
  → Copy Client ID & Client Secret

Step 2: Create .env File (1 min)
  Create file: .env
  Content:
    SHOPIFY_CLIENT_ID=your_id_here
    SHOPIFY_CLIENT_SECRET=your_secret_here
    REDIRECT_URI=http://localhost:9000/oauth/shopify/callback
    CHATBOT_WIDGET_URL=https://your-domain.com/chatbot-widget.js

Step 3: Install & Run (2 min)
  npm install express cors dotenv axios
  node shopify-oauth-server.js

Step 4: Test
  Open: http://localhost:9000/shopify-connect.html
  Enter: mystore
  Click: "Connect with Shopify" ✅

📊 HOW THE FLOW WORKS
───────────────────────────────────────────────────────────────────────────────

1. Customer visits your app
   ↓
2. Clicks "Connect with Shopify" button
   ↓
3. Enters their store name (mystore.myshopify.com)
   ↓
4. Frontend generates OAuth URL
   ↓
5. Redirects to Shopify login
   ↓
6. Customer logs in & approves permissions
   ↓
7. Shopify redirects back with authorization code
   ↓
8. Backend exchanges code for access token
   ↓
9. Fetches customer's shop information
   ↓
10. Automatically installs chatbot widget on their store theme
   ↓
11. Saves connection to database
   ↓
12. Shows success message ✅
   ↓
13. Chatbot appears on customer's website! 🎉
