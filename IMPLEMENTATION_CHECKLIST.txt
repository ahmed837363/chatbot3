PHASE 1: SETUP & CONFIGURATION (Do This First!)
═══════════════════════════════════════════════════════════════════════════════

Shopify Partner Account:
  ☐ Go to https://partners.shopify.com
  ☐ Create Shopify Partner account (free)
  ☐ Verify email
  ☐ Complete profile

Create Shopify App:
  ☐ Log in to Shopify Partners dashboard
  ☐ Click "Create an app"
  ☐ Choose "Create app manually"
  ☐ Fill in app details
  ☐ Save app

Get Credentials:
  ☐ Go to app → Configuration
  ☐ Copy Client ID (API Key)
  ☐ Copy Client Secret (API Secret Password)
  ☐ Save these somewhere safe!

Configure App Settings:
  ☐ Set Redirect URI: http://localhost:9000/oauth/shopify/callback
  ☐ Set App URL: https://your-domain.com
  ☐ Enable API Scopes (check all of these):
    ☐ write_products
    ☐ read_products
    ☐ read_orders
    ☐ write_settings
    ☐ write_themes
    ☐ read_themes
    ☐ write_theme_asset_modifications
    ☐ read_theme_asset_modifications
  ☐ Save changes

Create .env File:
  ☐ Copy .env.example to .env
  ☐ Fill in SHOPIFY_CLIENT_ID
  ☐ Fill in SHOPIFY_CLIENT_SECRET
  ☐ Fill in REDIRECT_URI
  ☐ Fill in CHATBOT_WIDGET_URL
  ☐ Save .env file

Add to .gitignore:
  ☐ Add ".env" to .gitignore
  ☐ Add ".env.local" to .gitignore
  ☐ Commit .gitignore change

PHASE 2: INSTALL DEPENDENCIES & START SERVER
═══════════════════════════════════════════════════════════════════════════════

Install Backend Dependencies:
  ☐ Open terminal
  ☐ Navigate to project root
  ☐ Run: npm install express cors dotenv axios
  ☐ Wait for installation to complete
  ☐ Verify: npm list (should show packages)

Start OAuth Server:
  ☐ Run: node shopify-oauth-server.js
  ☐ Look for message: "✓ OAuth callback server listening on port 9000"
  ☐ Note any errors

Test Server is Running:
  ☐ Open browser: http://localhost:9000/health
  ☐ Should return: { status: 'ok', service: 'shopify-oauth' }
  ☐ Server is working! ✓

  ☐ Check Shopify app settings exactly match
  ☐ Check for trailing slashes
  ☐ Check http:// vs https://
  ☐ Restart server after changing settings

If "Client ID not found":
  ☐ Verify .env file exists
  ☐ Check environment variables are set
  ☐ Verify credentials are correct
  ☐ Restart server after updating

  ☐ Verify widget URL is correct
  ☐ Check browser console for errors
  ☐ Clear Shopify theme cache
  ☐ Check theme edit code section

If OAuth callback fails:
  ☐ Check server logs
  ☐ Verify port 9000 is available
  ☐ Check firewall rules
  ☐ Verify Shopify app settings
