🚀 HOW TO GET STARTED (Quick Start Guide)
═══════════════════════════════════════════════════════════════════════════════

1. CREATE .env FILE
   Create file: .env
   
   SHOPIFY_CLIENT_ID=your_id_from_shopify
   SHOPIFY_CLIENT_SECRET=your_secret_from_shopify
   REDIRECT_URI=http://localhost:9000/oauth/shopify/callback
   CHATBOT_WIDGET_URL=https://your-domain.com/chatbot-widget.js

2. INSTALL DEPENDENCIES
   npm install express cors dotenv axios

3. START SERVER
   node shopify-oauth-server.js

4. TEST
   http://localhost:9000/shopify-connect.html
   
   Enter: mystore
   Click: "Connect with Shopify"
   ✓ Done!

  • POST /oauth/shopify/auth-url - Generates auth URL

  • POST /webhooks/shopify/uninstalled - Handles uninstall
  • GET /health - Health check
