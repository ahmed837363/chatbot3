🚀 HOW TO START (3 Simple Steps)
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Get Shopify Credentials (2 minutes)
  └─ Go to: https://partners.shopify.com
  └─ Sign up (free)
  └─ Create a custom app
  └─ Copy: Client ID & Client Secret

STEP 2: Create .env File
  Create file in project root:
  
  SHOPIFY_CLIENT_ID=your_id_here
  SHOPIFY_CLIENT_SECRET=your_secret_here
  REDIRECT_URI=http://localhost:9000/oauth/shopify/callback
  CHATBOT_WIDGET_URL=https://your-domain.com/chatbot-widget.js

STEP 3: Install & Run
  npm install express cors dotenv axios
  node shopify-oauth-server.js

  Then test at: http://localhost:9000/shopify-connect.html
