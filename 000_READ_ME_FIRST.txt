🚀 QUICK START (15 Minutes Total):
═══════════════════════════════════════════════════════════════════════════════

1. Go to: https://partners.shopify.com
   → Create account (free)
   → Create custom app
   → Copy Client ID & Secret
   ⏱ 5 minutes

2. Create .env file with:
   SHOPIFY_CLIENT_ID=your_id
   SHOPIFY_CLIENT_SECRET=your_secret
   REDIRECT_URI=http://localhost:9000/oauth/shopify/callback
   CHATBOT_WIDGET_URL=https://your-domain.com/chatbot-widget.js
   ⏱ 2 minutes

3. Run:
   npm install express cors dotenv axios
   node shopify-oauth-server.js
   ⏱ 5 minutes

4. Test:
   Open: http://localhost:9000/shopify-connect.html
   Enter store name and click "Connect"
   ⏱ 3 minutes

✅ DONE! Your integration is live! 🎉
